## Technical Implementation Details

### Build Script Architecture

**Clean Build Strategy:**
```bash
rm -rf build/ dist/
xcodebuild \
    -project PremiumTerminalShader.xcodeproj \
    -scheme PremiumTerminalShader \
    -configuration Release \
    clean build
```

**Verification Steps:**
1. Locate `.app` bundle in DerivedData
2. Verify executable exists: `Contents/MacOS/PremiumTerminalShader`
3. Validate app structure (Info.plist, Resources, Frameworks)

**Archive Creation:**
```bash
tar -czf PremiumTerminalShader-2026.05.22.tar.gz PremiumTerminalShader.app
shasum -a 256 PremiumTerminalShader-2026.05.22.tar.gz
```

### Homebrew Cask Structure

**Why Cask (Not Formula)?**
- GUI application (not command-line tool)
- Installs to `/Applications` (standard macOS location)
- Supports `.app` bundle installation
- Allows binary symlink for CLI access

**Installation Flow:**
```
brew install --cask iterm2-shader-cli
    ↓
Download tarball from GitHub releases
    ↓
Extract .app bundle
    ↓
Copy to /Applications/PremiumTerminalShader.app
    ↓
Create symlink: /opt/homebrew/bin/iterm2-shader
    ↓
Run postflight script (create preferences dir)
    ↓
Installation complete
```

**Uninstallation Flow:**
```
brew uninstall --cask iterm2-shader-cli
    ↓
Remove from /Applications
    ↓
Remove symlink from /opt/homebrew/bin
    ↓
Optional: brew cleanup --cask (remove from Caskroom)
    ↓
Full cleanup: brew zap --cask iterm2-shader-cli
    ↓
Remove preferences, cache, and user data
```

## Troubleshooting Guide

### Build Issues

**Error:** `xcodebuild: Command not found`  
**Fix:** Install Xcode from App Store, run `xcode-select --install`

**Error:** Build fails with code signing error  
**Fix:** Build script disables code signing with `-CODE_SIGNING_REQUIRED=NO`

**Error:** `.app` not found after build  
**Fix:** Check `build/DerivedData/Build/Products/Release/` directory

### Homebrew Issues

**Error:** `Cask iterm2-shader-cli not found`  
**Fix:**
```bash
brew untap yatharthkhattri/tap
brew tap yatharthkhattri/tap
brew update
```

**Error:** SHA256 mismatch  
**Fix:** Recalculate with `shasum -a 256` and update formula

**Error:** App damaged/quarantined  
**Fix:**
```bash
sudo xattr -rd com.apple.quarantine /Applications/PremiumTerminalShader.app
```
